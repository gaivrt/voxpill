# VoxPill 1.0.3

## 自定义录音快捷键

- 右键点击系统托盘中的 VoxPill，选择「设置快捷键…」。
- 直接按下想绑定的单键或组合键，全部松开后点击「保存」。
- 支持重新录入、取消和恢复默认右 Ctrl；托盘显示当前快捷键。
- 保存后自动生效并记住设置，录入期间暂停触发录音。
- 安装升级保留已有的 `config.toml`，包括快捷键及麦克风设置。

录音仍采用按住说话、松开提交。组合键松开任意成员后结束录音；Windows 保留的安全快捷键无法录入，日常使用时所选按键仍可能触发其他软件的快捷键。

## 下载

- `VoxPill-1.0.3-setup.exe`：Windows x64 安装包，推荐现有用户直接升级。
- `VoxPill-1.0.3-portable.zip`：免安装版，解压后运行 `VoxPill.exe`。手动升级便携版时保留自己的 `config.toml`。
- `SHA256SUMS.txt`：安装包及便携包的 SHA-256 校验值。
