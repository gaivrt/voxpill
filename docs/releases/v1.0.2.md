# VoxPill 1.0.2

- Keep recognition on Windows HighQoS so startup-launched background sessions do not fall onto EcoQoS execution-speed throttling.
- Add per-recognition gate, decode, punctuation, and total latency diagnostics.
- Reduce long-transcript overlay fitting from a linear suffix scan to a bounded binary lookup.
- Suppress preview hallucinations and final injection when the hotkey captures only silence or steady background noise.

The ASR models, text injection behavior, hotkey, and preview cadence are unchanged.
