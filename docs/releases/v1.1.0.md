# VoxPill 1.1.0 — cross-platform preview

Windows x64, macOS Apple Silicon / Intel, and Linux x86_64 (X11) are built on native
GitHub runners and published together after tests and package smoke checks pass.
Models are included; recognition runs offline.

- Windows retains the native transcript overlay, recorded hotkey settings and installer.
- macOS adds physical hotkey polling, Command+V insertion and a menu-bar app.
- Linux X11 adds physical hotkey polling and clipboard insertion.
- macOS/Linux store settings and logs in writable per-user directories.
- On macOS/Linux, keep the original window focused until decoding finishes;
  insertion is cancelled if focus changes. Hotkey settings accept names such as
  `ctrl_r`, `f8`, or `ctrl_l+shift_l+space`.

## Preview limitations and setup

macOS/Linux do not yet have the Windows transcript overlay. Native Wayland is
not supported. Linux requires PortAudio, Tk, xclip and an X11 desktop; a desktop
tray with menu support is optional (otherwise run the binary in a terminal).
On Ubuntu: `sudo apt install libportaudio2 python3-tk xclip`.

On macOS, move VoxPill.app into Applications and allow it in Privacy & Security
under Microphone and Accessibility; Input Monitoring may also be needed.
The app is not Developer ID signed or notarized. Use Finder's Open action and
the Privacy & Security approval UI if macOS blocks first launch.

Automated tests do not establish real-microphone or target-application behavior
on all desktops. macOS/Linux remain preview quality pending hands-on acceptance.
