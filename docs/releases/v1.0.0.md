# VoxPill 1.0.0

The first stable Windows release of VoxPill, a CPU-only offline Chinese/English push-to-talk typing app.

## Highlights

- Hold Right Ctrl to record and release it to insert the final transcript.
- Adaptive 1–2 second pseudo-streaming previews with a no-focus bottom overlay.
- One local INT8 Paraformer pipeline for preview and final recognition.
- Restores the original target window and inserts the final text exactly once.
- Per-user Windows installer with Start Menu, uninstall, and optional login startup.
- Self-contained portable ZIP; target machines do not need Python, `uv`, CUDA, or network access.

## Downloads

- `VoxPill-1.0.0-setup.exe` — recommended Windows installer.
- `VoxPill-1.0.0-portable.zip` — unzip and run `VoxPill.exe`.
- `SHA256SUMS.txt` — artifact integrity hashes.

## Notes

- Windows x64 only.
- The application is currently unsigned, so Windows SmartScreen may show an unrecognized-app warning on first launch.
- Offline models account for most of the approximately 300 MiB download size.
