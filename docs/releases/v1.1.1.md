# VoxPill 1.1.1 — subtitles on every supported desktop

macOS (Apple Silicon / Intel) and Linux X11 now show live transcript subtitles,
including recording status, character-by-character previews, final recognition
and automatic dismissal. Native panels stay above other windows without taking
keyboard focus or intercepting mouse clicks. Long text keeps the newest words
visible; new recordings replace older sessions without stale text flashing back.

macOS uses a non-activating AppKit panel; Linux uses Tk with X11 input and window
shapes. GUI helpers run on their own main thread in a subprocess and exit when
VoxPill exits. No new GUI framework dependency is needed.

Native package checks exercise rendering, Chinese/English text, focus retention,
click-through window settings, final display, stale sessions and auto-dismissal.
Render captures are retained as GitHub Actions artifacts. These automated checks
do not replace hands-on microphone and desktop acceptance.

Linux still requires an X11 session, PortAudio, Tk and xclip. Install a CJK font
if Chinese glyphs are absent (Ubuntu: `sudo apt install fonts-noto-cjk`). Native
Wayland is not supported. On macOS, grant Microphone and Accessibility permissions;
the app remains unsigned/not notarized. Keep the original input window focused
until recognition finishes on macOS/Linux.
